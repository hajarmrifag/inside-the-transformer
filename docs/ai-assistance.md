# Contribution and AI assistance

This repository is an extensively AI-assisted student research project. The student supplied the goal, scope and follow-up questions. An autonomous AI assistant performed the study design, implementation, literature review, local execution, analysis, documentation and publication audit; a research assistant agent helped review primary sources during the initial study.

No independent student implementation, independent statistical review, or demonstrated technical mastery is asserted by these artifacts. Application and CV wording explicitly says AI-assisted and describes verified project results rather than inventing personal contributions. The student's own subsequent reproduction, interpretation or technical explanation should be described only if actually performed.

IOI, activation patching, causal tracing and token/position analyses predate this project. Original task/circuit attribution belongs to Wang et al.; causal-tracing and methodology references are cited in the research report. This work contributes a local conceptual replication, a frozen-site counterbalanced donor comparison, failure analysis and an auditable reproduction package. It makes no global novelty claim.

AI-generated code and prose were checked against executed outputs and primary references. This does not constitute independent external peer review. The limitations of the model behavior, study design and audit are documented rather than removed from the application narrative.
